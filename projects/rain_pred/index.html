Rainfall Prediction on a Microcontroller

Embedded machine learning

ESP8266DHT22ThingSpeakMachine learningPython

Overview

The aim was to let a microcontroller make decisions on its own when rain is coming, such as alerting the people in a home or driving servos to close the windows.

How it works

  • Collected temperature and humidity readings over time with a DHT22 sensor and an ESP8266, logged to ThingSpeak
  • Cleaned the data and trained a classification model with an F1 score of 96.6
  • Deployed the trained model on an ESP8266 Wemos D1 so predictions run on the device itself
