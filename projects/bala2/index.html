Overview

This project implements and experimentally evaluates modern control algorithms on the M5Stack Bala2 Fire self-balancing robot. Rather than treating the robot as a finished product, I use it as a research platform for studying balance control, state estimation, system identification and real-time embedded control.

What I have done

  • Implemented and compared classical PID control, the Linear Quadratic Regulator (LQR) and Data-enabled Predictive Control (DeePC)
  • Characterised motor, PWM and encoder behaviour experimentally to model the system
  • Combined embedded C++, IMU sensor fusion, motor control and real-time estimation on the robot

Current work

Improving model accuracy through system identification, and studying the transition from model-based to data-driven control.
